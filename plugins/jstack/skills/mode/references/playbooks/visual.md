# Playbook：visual

用于用户指定设计、截图或现有页面作为参照的视觉与交互工作。

1. **固定参照**：记录参照、页面、视口、语言、主题、字体和必要数据。取得实际浏览器截图，说明差异；只给图片时，不能从图片推断未展示的交互。
   完成标准：比较双方的状态可复现；缺少必要参照时澄清，不能自行声称像素一致。
2. **实现**：按 [implement](../../../implement/SKILL.md) 在隔离 worktree 中修改，标明由 mode 派发后返回。先复用现有组件与 token，找共享布局根因；不靠裁剪、隐藏内容或改断点掩盖问题。
   完成标准：改动解释了观察到的差异，范围外行为保持。
3. **验证**：在约定视口和相邻关键尺寸比较截图及计算样式，操作键盘焦点、主要交互与长文本状态。浏览器工具不存在时标 BLOCKED，不用 lint 或静态截图生成替代真实操作。
   完成标准：约定状态均有实际证据，剩余差异明确列出。
4. **交付**：将参照和验证步骤交给 [finish](../../../finish/SKILL.md) 独立验证并交付 PR/CI。
   完成标准：报告视觉与功能结果及未验证边界。
