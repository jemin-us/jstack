# 中文专项

用中文写给 agent 的文字时逐条检查。

## 1. 用结构或脚本控制长度

要控制长度时，规定结构（例如"三段：改了什么、验证了什么、还有什么"），或用脚本检查。精确字数、句数是中文下最难满足的约束，模型普遍写超长。

## 2. 命令、路径、标识符保留英文原文

技术术语、产品名、代码标识符、命令、路径、错误信息照原文写在中文句子里，中文夹英文术语不影响效果。其余内容都用中文：不在中文后面括注英文翻译，不用英文作章节标题。

## 3. 写明输出语言

需要中文输出时，在 skill、`CLAUDE.md` 或系统提示词里写明，不依赖模型推断。

## 4. 中文写，不必改写成英文

把中文指令改写成英文不会更稳定，中文也不比英文省 token。用团队最自然的语言写。

## 5. 同一概念始终用同一个词

一个概念选定一个中文词或英文术语后，全文只用它，不换同义词。这同时让它成为引导词，见 [principles.md](principles.md) 的"引导词"一节。

## 6. 模糊量词换成可检查的条件

"适当""尽量""必要时"让 agent 自己定标准。改写成条件或数量，例如"超过 3 个文件时"。
