# 检查清单

## 动笔前

- [ ] 明确了 2–3 个用例，每个用例包含触发说法、执行步骤和交付结果
- [ ] 确定了所需工具：内置工具、MCP 或脚本
- [ ] 确定了与相邻 skill 的边界
- [ ] 已读目标仓库的约定（写入已有 skill 仓库时）

## 开发中

以下各项由校验脚本自动检查：

- [ ] 文件夹名使用 kebab-case，且与 `name` 一致
- [ ] 主文件名为 `SKILL.md`
- [ ] frontmatter 有 `---` 分隔
- [ ] description 不超过 1024 字符，且不含 `<` `>`
- [ ] 文件夹内没有 `README.md`
- [ ] 正文链接的文件都存在

以下各项需人工检查：

- [ ] description 使用中文关键词，并写明触发场景和边界
- [ ] 全文没有中英混排，英文只用于术语、产品名和标识符
- [ ] 关键约束写在正文开头
- [ ] 每个步骤都有具体动作和完成标准
- [ ] 写明了出错时的处理方式
- [ ] 至少有 1 个示例
- [ ] 每个 references 文件都注明了何时读取
- [ ] 需要确定结果的检查已写成脚本

## 交付前

- [ ] 直接说法能触发
- [ ] 换一种说法也能触发
- [ ] 无关话题和相邻 skill 的说法不会触发
- [ ] 功能测试通过
- [ ] 工具集成可用（有工具集成时）
- [ ] 已按仓库约定登记和补充文档（写入已有 skill 仓库时）

## 上线后

- [ ] 在真实对话中试用
- [ ] 观察是否触发不足或触发过度
- [ ] 根据反馈修改 description 和正文
- [ ] 升级 `metadata.version`
