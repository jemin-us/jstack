# 检查清单

审查 skill 时逐项检查，每项给出"符合"或"不符合及所在行"。

## 结构

- [ ] 校验脚本没有"错误"
- [ ] description 包含触发句和做什么；有相邻 skill 时包含边界
- [ ] 每个步骤都有具体动作和完成标准，完成标准写的是做完后的状态
- [ ] 同一个约束只出现一处；"硬性规则"里没有某一步专属的约束
- [ ] 示例和常见问题没有复述步骤；流程类 skill 两者都有
- [ ] 每个 `references/` 文件都从 `SKILL.md` 直接链接，并有一句写明何时读取的指针；超过 100 行的在开头列出目录
- [ ] 没有模型不用提醒就能做对的内容，没有会过期的信息（日期、版本号）
- [ ] 结果确定的检查已写成脚本
- [ ] 只引用其他 skill 的 `SKILL.md`，没有引用它的内部文件
- [ ] 已按仓库约定登记和补充文档（写入已有 skill 仓库时）

## 测试

- [ ] 直接说法和换一种说法都能触发
- [ ] 无关话题和相邻 skill 的说法不会触发
- [ ] 功能测试通过；有工具集成时工具调用成功
- [ ] 同一任务跑 3 次，输出结构一致

## 上线后

- [ ] 在真实对话中试用，记录触发不足或触发过度的说法
- [ ] 根据记录修改 description 和正文
