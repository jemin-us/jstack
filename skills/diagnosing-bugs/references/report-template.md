# 诊断结论与收尾模板

第 5 步写诊断结论、第 7 步收尾时读取本文件。

## 诊断结论

```markdown
## 当前行为
<用户看到的症状，含报错原文或错误输出>

## 期望行为
<修复后应有的表现>

## 必须保持不变的行为
- <修复不能影响的相邻行为，交给 accept 做回归检查>

## 根因
<被证实的猜想，以及支撑它的运行时证据>

## 验收检查
1. `<复现命令>` → <期望结果>（当前：失败）
```

## 收尾

```markdown
## 改了什么
- <commit 列表：失败测试一个、修复一个；.git 只读时说明未分开提交>

## 验证了什么
修复前：
<原样贴出失败输出>

修复后：
<原样贴出通过输出>

- 原始复现命令：<已运行 / 未运行，附原因>
- 调试前缀清理：<已搜索，无结果>

## 还有什么
- <未验证的部分、缺少合适测试接缝的发现、需要 accept 检查的内容>
```
