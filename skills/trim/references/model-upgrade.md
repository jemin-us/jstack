# 模型升级后重跑精简流程

换了新模型后重跑精简流程时读取本文件。

1. **基线盘点**：运行 `scripts/inventory.py` 和 `scripts/usage.py`，拿到三端（Claude Code、Codex、agy）每轮加载字符数与各 skill 的真实会话调用次数。
2. **重测文字规则**：对照 `docs/agent-rules.md`，把“由什么强制”一栏为“无”的规则抽出来，在不加载该文字规则的对照会话里实测新模型会不会自己照做。确认不写也会照做的条目，列入删除清单并在台账写明 `<模型名> 实测不写也照做`。
3. **升级强制层级**：仍需保留的文字规则，按 `SKILL.md`“放置位置”表优先升级为检查脚本、CI 或 `PreToolUse` hook 注入（例如把“做 Y 之前先读 X”改成写 Y 时自动注入 X）。
4. **先搬家再压缩并验真**：用户确认清单后，按“先搬家（原样整段搬）→ 再压缩 → `vanished.py` 对账 → 独立 subagent 按关键名词盲查 → 新加载位置正反向暗号验证”闭环执行，然后更新台账。
